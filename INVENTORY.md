# Inventory

to be used in the exams of this subject.

I've used Claude to create an intuitive interface,
so I can spend minimal time doing this during this short period of time
I have to accomplish this exam.

Modify and run the Octave files to get the results.
And read their respective documentation in the Markdown files,
which includes when and how to use it.
