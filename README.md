# Computational Methods (TEC 217) Exercises (2026.1)

This repository contains the exercises for the Computational Methods (TEC 217) course at UEFS. 

The exercises are organized into folders based on the topics covered in the course. Each folder contains Matlab/Octave files with the exercises and their solutions.

This was prepared to be ran on VsCode with the Octave extension.
But you could also run from Matlab or Octave directly.
